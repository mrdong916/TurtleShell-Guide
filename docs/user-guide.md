## 安装与更新

### 首次安装

1. 确认手机为 **Android 12 及以上**，车机支持**无线 CarPlay**。
2. 打开 [Releases](https://github.com/mrdong916/TurtleShell-Guide/releases)，选择龟壳互联版本，阅读发布说明。
3. 展开 **Assets（资源）**，下载 `.apk` 文件。`Source code` 压缩包不能安装到手机。
4. 在手机打开 APK，按系统提示允许安装，完成后打开应用。
5. 按首页提示完成激活、权限准备和车机选择。未激活时也可先查看设置、帮助与桌面预览。

地图和音乐使用手机上已经安装的应用，请先完成它们的登录与首次使用设置。

### 更新应用

**直接覆盖安装，不要先卸载或清除应用数据。**

1. 停车并结束当前连接。
2. 在「设置 → 关于与更新 → 检查更新」查看提示，或访问 Releases。
3. 下载新版 APK，手动完成安装。
4. 重新打开应用，保持联网完成授权验证，再连接车机。

正常覆盖更新会保留设置和设备绑定。若提示必须更新，请完成更新后再发起新连接。

安装失败或提示冲突时，先确认文件来自本仓库 Releases，再到[交流群](../README.md#加入交流群)反馈，不要直接卸载重装。

## 激活与设备绑定

入口：**设置 → 激活与授权**，也可按首页准备步骤进入。

1. 向维护者获取激活码，确认适用期限。
2. 手机保持联网，输入激活码，点击「激活此手机」。
3. 页面显示激活成功后，继续准备投屏权限。

授权绑定手机，更换车机无需换绑。永久授权没有授权到期日；限时授权以页面显示的到期时间为准。

### 联网验证

0.3.5 中，永久和限时授权均**最多离线使用 24 小时**，具体以授权页的「最迟联网验证」和「授权到期」时间为准。出发前建议打开应用并保持网络可用。

- 提示需要验证：恢复网络，点击「立即联网验证」或「验证 / 恢复已有授权」。
- 提示授权到期：联系维护者处理，再按页面提示重新验证。
- 正在进行的行程不会因授权期限被强制中断；到期后需要验证才能开始新连接。

在线地图和音乐仍需要互联网，授权离线可用不代表在线内容可以使用。

### 换手机或重新安装

更换手机、刷机、卸载或清除应用数据后，可能需要重新绑定。请在「激活与授权 → 设备绑定与换机」查看信息，私下联系群管理员处理；不要在群内公开激活码或完整设备标识。

授权验证需要联网，使用期间会更新设备授权与在线状态。诊断日志保存在本机，由你选择是否导出。

## 准备投屏权限

入口：**设置 → 权限与后台 → 权限方式**。

| 方式 | 准备方法 |
| --- | --- |
| Shizuku（默认） | 按 [Shizuku 官方指南](https://shizuku.rikka.app/zh-hans/guide/setup/)启动服务，再回龟壳互联允许使用 |
| Root | 适用于已经 Root 的手机，选择后按超级用户管理器提示授权 |

两种方式选一种即可。安装龟壳互联不会自动获取 Root。

手机重启后，Shizuku 通常需要重新启动。连接前先确认服务就绪；附近设备、通知等权限按应用提示处理。更换权限方式前，请先结束连接。

音乐信息权限是可选项，不影响首次连接准备。

## 第一次连接车机

请停车后操作，第一次连接时建议保持手机亮屏。

1. 车机进入无线 CarPlay 配对或连接页面。
2. 手机开启蓝牙与 Wi-Fi，在系统蓝牙设置中完成配对。
3. 回龟壳互联首页选择对应车机，也可从「设置 → 车辆与连接」选择。
4. 确认激活有效、权限服务就绪，点击「连接车机」。
5. 按手机和车机提示完成配对、授权或加入网络。
6. 在车机确认桌面可见、触摸可用，再播放音乐检查声音。

车机 Wi-Fi 主要用于连接，**不等于手机能上网**。在线地图和音乐通常还需要移动数据，连接后可用地图搜索或在线歌曲检查网络。

## 日常连接与结束

- **再次连接**：确认权限服务、授权和网络可用，选择车机，点击「连接车机」。
- **取消连接尝试**：连接过程中点击取消，等待状态结束后再重试。
- **结束投屏**：点击首页或连接通知中的结束入口，并确认。
- **临时回原车界面**：点击车载桌面的「车机」卡片；再次从车机选择 CarPlay 返回。
- **更换车机或权限方式**：先结束连接，再修改设置。

结束投屏后，如需继续导航，请在手机地图中检查路线与导航状态。同一车机只运行一个投屏会话。

## 地图与导航

入口：**设置 → 地图与导航 → 默认地图与显示模式**。

可选择已安装的高德、百度或腾讯地图。首次使用前，先在手机上完成地图的登录、权限和隐私确认。

### 高德显示模式

| 模式 | 使用方式 |
| --- | --- |
| 车载页面（默认） | 在车机上使用车载界面，不提供手机普通导航路线交接 |
| 普通地图交接 | 通过「地图切换」确认在手机与车机间切换；可能重新加载，请核对路线 |

模式修改后**下次连接生效**。车载页面不可用时，可改为普通地图交接并重新连接。

### 展开与显示比例

车载地图可直接点按、拖动，使用侧栏地图按钮展开或收起。

「设置 → 显示与布局 → 地图显示比例」可调 **50%–100%**，默认 **75%**。比例调小会显示更多内容，文字与按钮也会变小；松手后生效。点击「恢复地图默认比例」可回到 75%。

不同地图和手机的排版可能不同，请优先保证文字可读、触摸准确。

### 手机与车机间切换

普通地图交接模式下，进入「地图与导航 → 地图切换」，按页面提示选择并确认。也可使用出现的首页或连接通知入口。

在手机选好路线后，再确认交给车机。切换后请核对目的地和导航状态，必要时在地图内继续导航或重新规划；当前不保证路线无损接续。

## 音乐与声音

入口：**设置 → 音乐与声音**。

- **默认音乐应用**：自动选择或指定手机上已安装的播放器。
- **连接后自动播放**：按需开启，连接后尝试继续已暂停的音乐；未播放时可手动打开播放器。
- **传输媒体声音**：控制是否传输声音，修改后下次连接生效。
- **音乐信息权限**：到系统「通知使用权」允许龟壳互联，用于显示歌名、封面和控制播放。

点击车载音乐卡的封面或歌名可打开音乐应用；播放、暂停和切歌按钮单独操作。歌词和控制功能取决于播放器支持情况。

有歌名但没有声音时，先检查播放器是否正在播放、手机与车机媒体音量，再检查「传输媒体声音」。电话继续使用原车蓝牙。

## 桌面与显示

| 设置入口 | 可以调整什么 |
| --- | --- |
| 外观与日夜 | 手机主题；车载壁纸、卡片材质与布局预览 |
| 桌面与应用 → 管理桌面应用 | 选择车机应用列表中显示的应用 |
| 显示与布局 | 图标大小、排列密度、地图比例、视频码率等 |
| 桌面与应用 → 高级应用设置 | 应用横屏等兼容选项 |

手机主题不改变地图配色。壁纸和布局预览仅供参考，实际以车机显示为准。

首次使用建议保留默认值，连接正常后一次只调整一项。码率、清晰度和安全留边等设置按页面提示在下次连接生效；遇到卡顿时不要一味提高画质。

## 手机暗屏与后台运行

入口：**设置 → 权限与后台**。

| 手机屏幕模式 | 效果 |
| --- | --- |
| 跟随系统 | 使用手机原来的息屏时间 |
| 自动息屏 | 投屏时调整息屏时间，断开后恢复；锁屏后能否正常使用需本机确认 |
| 兼容暗屏 | 显示可点击退出的黑色遮罩，手机仍亮屏并耗电，需要悬浮窗权限 |
| 保持亮屏 | 投屏期间保持手机亮屏，需要悬浮窗权限 |

自动息屏和兼容暗屏可选择无操作 30 秒、1 分钟或 5 分钟后执行。

息屏后断连时，同时检查「Android 电池优化」和手机厂商的后台限制。例如，小米 / HyperOS 可选择「无限制」，三星需检查应用是否被放入休眠列表。

锁屏后黑屏或无声时，先解锁对照，再使用「屏幕问题排查」中的检查入口。若手机息屏时间未恢复，可点击「重新检查与恢复超时」。

## 常见问题

| 现象 | 建议处理 |
| --- | --- |
| 下载页没有 APK | 等待维护者发布，安装包会放在 Releases 中 |
| 找不到车机 | 确认支持无线 CarPlay，先完成系统蓝牙配对，并允许附近设备权限 |
| 一直连接中 | 检查车机、权限服务与网络，处理两端提示；取消后等待状态结束，再重试 |
| 重启手机后连不上 | 重新启动 Shizuku，或检查 Root 授权 |
| 已连接但黑屏 | 退出倒车 / 360 影像或原车提示，重新选择 CarPlay；解锁手机检查是否恢复 |
| 有画面无声 | 检查播放状态、两端媒体音量和声音开关，重新连接后再试 |
| 有声音但没有歌曲信息 | 在「音乐与声音」开启音乐信息权限，再播放一首歌 |
| 地图或音乐不能联网 | 检查移动数据、流量、VPN 与系统网络设置 |
| 地图打不开 | 先在手机完成首次使用设置；按提示重试，或更换地图模式 |
| 地图文字太大、有黑边 | 尝试默认 75% 比例；不同应用与手机可能仍有布局差异 |
| 切换后导航中断 | 在地图内检查最近导航或重新规划，切换后务必核对路线 |
| 息屏后断连 | 检查屏幕模式、后台省电限制和权限服务 |
| 激活或更新失败 | 保持联网，记录页面提示，到交流群反馈；不要清数据重装 |

不同手机、系统、地图和车机的兼容性存在差异。Android 12 / 12L 使用 Shizuku 时可能出现声音不可用；横屏、锁屏和长时间运行也需本机验证。当前不提供有线 CarPlay、仪表 / HUD 导航输出或车机麦克风接管。

手机显示连接成功不代表车机画面、触摸与声音全部正常，请在停车状态下逐项确认。

## 诊断与反馈

**使用问题统一通过[微信交流群](../README.md#加入交流群)反馈。**

反馈时请说明：

- 龟壳互联版本、手机型号、Android / ROM 版本。
- 使用 Shizuku 还是 Root，车机型号。
- 发生时间、操作步骤和页面提示。
- 画面、触摸、声音分别是否正常，是否只在锁屏或重连时出现。

需要日志时，打开「设置 → 使用帮助 → 诊断与日志」：

1. 开启「记录连接日志」。
2. 复现问题，选择类型并点击「标记刚才发生的问题」。
3. 点击「导出日志包」，按群管理员指引私下提供。

日志可能包含设备名、网络标识、曲名等信息，不会自动上传。请勿在群内公开激活码、完整设备标识、原始日志或含个人信息的截图。激活、换绑等事项请私下联系群管理员。

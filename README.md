## 下载与安装

前往 **[Releases](https://github.com/mrdong916/TurtleShell-Guide/releases)**，选择「龟壳互联 / TurtleLink」版本，在 **Assets** 中下载 `.apk`，不要下载 `Source code` 压缩包。

- **首次安装**：Android 12 及以上，车机支持无线 CarPlay；手机需可用的 Shizuku 或已有 Root，首次使用需联网激活。
- **已有用户升级**：直接覆盖安装，**不要卸载或清除数据**；更新后联网验证授权。

> 应用 APK 待发布（2026-10-27）。后续请从 Releases 下载正式发布的龟壳互联安装包。

## 首次连接

请停车后操作，保持手机蓝牙、Wi-Fi 开启；在线地图与音乐通常还需移动数据。

1. **激活**：安装后按首页提示，在「设置 → 激活与授权」输入维护者提供的激活码。
2. **授权**：在「设置 → 权限与后台」准备 [Shizuku](https://shizuku.rikka.app/zh-hans/guide/setup/) 或已有 Root。
3. **配对**：车机进入无线 CarPlay，手机完成蓝牙配对，回应用选择对应车机。
4. **连接**：点击「连接车机」，处理系统提示，确认车机画面、触摸和声音正常。

地图、音乐、壁纸、暗屏、授权与故障排查，见 **[完整使用指南](docs/user-guide.md)**。当前指南对应 0.3.5；不同手机和车机表现有差异，实车效果仍需验证。
